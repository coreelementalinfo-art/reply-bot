# Telegram Reply Bot

## Project Overview
A Telegram bot that acts as a bridge between users and a specific group chat. It forwards messages from users to a group, and when a group member replies to that forwarded message, the bot sends the reply back to the original user.

## Tech Stack
- **Language:** TypeScript (compiled to JavaScript)
- **Runtime:** Node.js
- **Core Library:** Telegraf (Telegram Bot API framework)
- **Build Tool:** TypeScript compiler (`tsc`)
- **Package Manager:** npm

## Project Structure
```
src/app.ts     - Main bot logic
dist/          - Compiled output (generated by build)
package.json   - Dependencies and scripts
tsconfig.json  - TypeScript configuration
```

## Required Environment Secrets
- `BOT_TOKEN` - Telegram bot token (from @BotFather)
- `GROUP_ID` - Telegram group chat ID where messages are forwarded

## Scripts
- `npm run build` - Compile TypeScript to JavaScript in `dist/`
- `npm start` - Run the compiled bot

## Workflow
- **Start application** - Runs `npm start` as a console service (not a web server)
